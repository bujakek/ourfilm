A wedding photo app only works when guests actually use it. OurFilm removes the
download step: one QR code opens the wedding's shared camera directly in each
guest's mobile browser.

Everyone uses the same event camera, but receives their own finite roll. The
host chooses 5, 10, 16, 24 or 36 shots per person and decides whether the
gallery opens immediately or when the event ends.

## How the guest camera works

1. The host creates the event and chooses the roll length.
2. OurFilm produces one QR code and shareable link for the wedding.
3. A guest scans, enters their name and starts taking photos. There is no app
   store, account or password.
4. The camera always shows how many frames remain.
5. Every committed photo joins the private event gallery and the host can
   download the complete album later.

## Why use a finite roll?

A disposable camera does not offer endless shots. That constraint is part of
the experience: guests pause before pressing the shutter, spend less of the
reception looking through a screen and capture moments they would otherwise
leave to somebody else.

A 24-frame roll is a practical starting point for a full wedding. Shorter
events can use 10 or 16; an all-day celebration can use 36.

## When should the photos appear?

| Reveal setting | Best when                                                         |
| -------------- | ----------------------------------------------------------------- |
| Immediately    | Guests should browse the shared album during the celebration      |
| At event end   | Everyone should discover the finished wedding film together later |

The host sees every photo and can hide individual images from the guest
gallery. Guest viewing can remain disabled if the album is meant only for the
couple.

## What guests do not need

Guests do not need to:

- install an iPhone or Android app;
- create an account;
- remember an invitation code or password;
- upload a whole camera roll after the wedding;
- learn a separate camera interface for one evening.

The QR code opens the camera that belongs to the event. That short path matters
when the same wedding includes different ages, devices and levels of technical
confidence.

## What OurFilm does not include

OurFilm is focused on still photography. It currently has no video uploads,
audio guestbook, filters or live slideshow. It also does not import existing
camera-roll photos. Choose a general upload gallery instead if collecting every
file after the event matters more than the finite-camera experience.

## Frequently asked questions

### Does it work on iPhone and Android?

The guest experience opens in a modern mobile browser, without a separate app.

### What happens when a guest runs out of shots?

They cannot take another photo. The host-selected roll is deliberately finite,
just like a disposable camera.

### Can guests see the photos immediately?

Yes, if the host chooses immediate reveal. The host can instead keep them
hidden until the event ends or keep guest viewing disabled.
