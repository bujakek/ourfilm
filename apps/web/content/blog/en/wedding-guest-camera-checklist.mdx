Use this checklist before printing a QR code for a digital wedding guest
camera. The critical work is not generating the code; it is testing the complete
guest flow and preserving the final gallery.

## Event setup

- [ ] Final event name and date are correct.
- [ ] Capture end time uses the venue's timezone.
- [ ] The per-person roll fits the event length.
- [ ] Immediate or end-of-event reveal is intentional.
- [ ] Guest gallery access matches the privacy plan.
- [ ] The host can hide unwanted photos and download the album.

## Phone testing

- [ ] Scan on a current iPhone and Android phone.
- [ ] Test from a signed-out or private browser.
- [ ] Grant camera permission and take a real photo.
- [ ] Confirm the shot count changes only after a successful upload.
- [ ] Test mobile data and the venue network if available.
- [ ] Check what guests see before and after the reveal.

## Print and placement

- [ ] Every printed code opens the final event URL.
- [ ] Contrast and quiet space remain clear after printing.
- [ ] A short fallback URL is readable.
- [ ] Cards explain the action, limit and reveal.
- [ ] Codes appear on tables and near active photo areas.
- [ ] Someone is assigned to mention the camera once.

## After the wedding

- [ ] Review and moderate the gallery.
- [ ] Download the complete archive.
- [ ] Compare the expected and downloaded file counts.
- [ ] Open several large files.
- [ ] Keep a second independent backup.
- [ ] Close uploads or remove access when no longer needed.
